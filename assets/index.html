LCO Guide

      

        
Interface

        
Explorer — left panel, click files to open in editor.

        
Editor — center, Monaco Editor with syntax highlighting.

        
Terminal — bottom, multi-tab PTY bash. + new, ✕ close, >_ toggle.

        
Preview ◉ — top-right toolbar. Opens a web preview panel on the right side. Enter a URL (e.g. http://127.0.0.1:8080) and press → to load a local dev server in an embedded iframe. Click ◉ again to close.

        
Commands (in Terminal)

        
git clone <url> — sync repositories

        
claude — Claude CLI interactive AI

        
python3 file.py / node file.js — run scripts

        
pkg install <pkg> — install tools (git, clang, vim)

        
npx serve . -p 8080 — start dev server for preview
